# E-Commerce Data Analysis Using Python

## Project Overview
Analyzed an online retail dataset using Python to understand sales performance, popular products, and revenue by country.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Excel Dataset
- Visual Studio Code

## Key Features
- Dataset loading and analysis
- Total revenue calculation
- Top 10 products by quantity sold
- Country-wise revenue analysis
- Monthly sales analysis
- Monthly sales chart
- Top 10 countries revenue chart

## Key Findings
- Total dataset records: 541,909
- Preliminary total revenue: £9,747,747.93
- Top product by quantity: PAPER CRAFT, LITTLE BIRDIE
- Highest-revenue country: United Kingdom

## Files
- `python_analysis.py` — Python analysis code
- `monthly_sales_chart.png` — Monthly sales visualization
- `country_sales_chart.png` — Country-wise revenue visualization
- `data/` — Dataset folder

## Learning Outcome
Practiced data cleaning concepts, data aggregation, revenue analysis, and data visualization using Python.
